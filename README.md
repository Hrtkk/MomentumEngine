# MomentumEngine

A forward paper test of NSE momentum and breakout strategies, chosen by a pre-registered, survivorship-free backtest (E2, 2013–2026). Each strategy is a ₹60,000 paper book. A concise report arrives every weekday at about 11:00 IST.

Start with [CLAUDE.md](CLAUDE.md) and [ROADMAP.md](ROADMAP.md). Not investment advice.
